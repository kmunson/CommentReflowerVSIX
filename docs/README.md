# Comment Reflower AI

Comment Reflower AI is a plugin for Visual Studio 2026 that reflows the text in
source code comments so the word wrapping is even.

These pages are the help for Comment Reflower AI. The Comment Reflower
extensions for Visual Studio 2017, 2019, 2022 and 2026 have their own help,
which opens from the **Help** button in their settings dialog.

It does more than simply wrap all the text in comment blocks. It attempts to
recognise and wrap appropriately:

- bullet points
- lines that should always break the flow of text
- XML preformatted blocks
- HTML break commands

For information on running Comment Reflower on a file, see
[Commands](Commands.md).

For information on configuring Comment Reflower to handle your particular
comment blocks, bullet points and break flow lines, see
[Settings](Settings.md).
