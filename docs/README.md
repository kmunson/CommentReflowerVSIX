# Introduction

Comment Reflower is a Plugin for Visual Studio 2017, 2019, 2022 and 2026 to reflow the text in comments in source files to have even word wrapping.
It does more than simply just wrapping all text in comment blocks. It attempts to recognise and wrap appropriately:

- bullet points
- lines that should always break flow of text
- XML preformat blocks
- HTML break commands

For information on running Comment Reflower on a file see [Commands](commands.md).

For information on configuring Comment Reflower to handle your particular settings for comment blocks, bullet points and
break flow lines, see the [Settings section](settings.md).
